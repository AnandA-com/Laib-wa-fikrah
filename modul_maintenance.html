Panduan Pemeliharaan, Update Data, dan Troubleshooting

Tujuan Dokumen: Memberikan panduan teknis bagi pengelola aplikasi untuk melakukan pembaruan konten, manajemen aset, dan perbaikan error ringan guna menjaga stabilitas aplikasi.

1. Struktur Direktori & File

Sangat penting untuk menjaga struktur folder agar aplikasi tidak mengalami Broken Link (Gambar tidak muncul).

/LaibWaTaallam-Rancangan-UIUX/
├── index.html            (File Utama / Source Code)
└── /assets/
    ├── app-background.jpg    (Background Utama)
    ├── welcome-background.jpg (Background Welcome Screen)
    └── /vocab/
        ├── kelas.jpg            (Gambar Kosakata)
        ├── buku_tulis.jpg         (Gambar Kosakata)
        └── ... (File .svg/.jpg lainnya)

2. Update & Penambahan Kosakata

Kosakata disimpan di dalam array JavaScript di dalam file index.html. Cari bagian variabel vocabulary.

Cara Mengedit Kata:

  1. Buka index.html dengan teks editor (VS Code/Notepad).
  2. Cari kata kunci const vocabulary = [.
  3. Edit objek kata yang diinginkan. Contoh:
    { word: "مدرسة", translation: "sekolah", category: "Bangunan", level: "Mudah", image: "assets/vocab/sekolah.jpg" }
  4. Simpan file dan Refresh browser.
⚠️ PERINGATAN: Pastikan setiap objek memiliki tanda koma (,) di akhir kurung kurawal } kecuali pada objek terakhir dalam array.

3. Manajemen Aset Gambar

Jika ingin mengganti gambar kosakata dengan foto baru:

  • Nama File: Pastikan nama file baru sama persis dengan nama file lama (contoh: tas.jpg).
  • Format File: Jika mengganti dari .svg ke .jpg, Anda WAJIB mengubah ekstensi file di dalam kode index.html.
  • Lokasi: Simpan selalu di dalam folder assets/vocab/.

4. Update Tautan Media Sosial

Untuk mengganti link Instagram, TikTok, atau Facebook:

  1. Cari tag <nav class="footer-socials"> di bagian bawah file index.html.
  2. Ganti bagian href="URL_LAMA" menjadi href="URL_BARU".
  3. Ganti teks di dalam tag <span>Nama Lama</span> menjadi nama baru.

5. Troubleshooting (Solusi Masalah)

Masalah Solusi
Gambar tidak muncul (X) Cek apakah nama file di folder assets/vocab/ sama persis dengan yang tertulis di kode (termasuk huruf besar/kecil).
Audio tidak berbunyi Pastikan speaker aktif dan browser tidak dalam mode "Mute". Beberapa browser mewajibkan klik satu kali di halaman sebelum audio bisa berjalan.
Halaman Putih/Blank Cek apakah ada tanda petik atau koma yang terhapus saat mengedit kosakata.

6. Strategi Backup & Keamanan

  • Manual Backup: Copy seluruh folder LaibWaTaallam-Rancangan-UIUX ke Google Drive atau Flashdisk setiap kali melakukan update besar.
  • Version Control: Disarankan membuat salinan file index.html.bak sebelum melakukan pengeditan kode yang kompleks.
